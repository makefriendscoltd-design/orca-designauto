# Hub detail-page style references

The hub exposes three visual styles. These display labels are not the revision
numbers of old product pages:

- Family ebook (latest): `landing/ebook-landing-page-v7/detail.html`.
- Pudufu ver2: `references/detail-styles/landing/aimax-threads-premium/detail_threads_premium_pudufu.html` (740px).
- Titan ver3: `references/detail-styles/landing/makefamily-membership/detail_membership_titan.html`.

The legacy originals and their 60 local HTML/CSS/font/image dependencies are
preserved byte for byte from the existing Mac design workroom. SOURCE_MANIFEST
records their SHA-256 values. They have no external asset dependencies.

For a new product, use the selected HTML/CSS as the visual reference and replace
its copy, evidence, images and offer only with facts from the user's supplied
material. Example prices, reviews and results are historical reference content,
not facts about the new product. For an edit, copy the selected master and assets
into the job and preserve the original dimensions. Preserve the actual original
revision number in provenance; do not rename v7 to v1 on disk.

No publishing, account credentials, API calls or external registration is included.
