# 원고 → 상세페이지 → 카페24 등록

카페·블로그에 쓴 모집글을 그대로 붙여넣으면 **판매 가능한 상세페이지로 바꿔 등록까지** 한다.
원고는 순서가 없고 길다. 그걸 **설득 순서로 재배열하는 게 이 스킬의 핵심**이다.

## 0-A. 손대기 전에 — `references/design-system.md` 의 맨 앞 세 절을 읽는다

**AI slop 금지 목록 · 공간 체계 · 스토리텔링 순서.** 이걸 건너뛰면 시안이 반려된다.
26-07-29 에 시안을 네 번 갈아엎고 나온 규칙이라 취향 문제가 아니다.

세 줄 요약:
- **그라디언트·글로우·생성 3D·형광 3색 금지.** "빛"이 아니라 "잉크"로 만든다
- **섹션 패딩 200px, 나열 항목은 절대 붙이지 않는다.** 공간감이 몰입감이다
- **제 주장으로 시작하지 않는다.** 상황묘사 → 속말 → 욕구 → 지목 → 진단 → 해법 순

## 0-B. 만들기 전에 — 같은 유형을 먼저 연다

**이걸 건너뛰면 매번 품질이 리셋된다.** 범용 템플릿에서 새로 지으면
이미 검증된 컴포넌트를 놔두고 비슷한 걸 다시 발명하게 된다. (실제로 그렇게 한 적 있음)

| 만들 것 | 먼저 열어볼 것 |
|---|---|
| 무료 웨비나·특강 모집 | `design/makefamily-webinar/detail_webinar.html` |
| 무료 전자책·리드마그넷 | `design/aimax-ebook/detail_v2.html` |

열어서 **섹션 순서 · 쓰인 컴포넌트 · 전체 길이** 세 가지를 확인하고 시작한다.
컴포넌트 카탈로그와 유형별 표준 구조는 `references/design-system.md`.

## 1. 원고에서 뽑아낼 것

원고를 읽고 아래를 표로 정리해 **사용자에게 먼저 확인받는다.** 없는 항목은 물어본다.

- 상품명 / 한 줄 정의
- **일시·장소·분량** (웨비나면 날짜·시각·소요시간, 전자책이면 페이지수)
- **정가와 판매가** (무료면 "0원"과 상당가 앵커)
- 타깃 — 원고의 "이런 분께" 문단이 있으면 그대로 쓴다
- **증거** — 수치, 실적, 서류, 후기, 스크린샷. 첨부 이미지가 여기 해당한다
- 강사·저자 — 이름, 직함, 경력, **1인칭 스토리**
- 신청자 혜택 / 보너스
- 희소성 — 정원, 마감일, 인상 예고, 다시보기 유무
- CTA 링크

**첨부 이미지는 캡션이 메시지를 지고, 이미지는 신뢰만 진다.**
스크린샷 속 작은 글씨는 모바일에서 안 읽힌다. 핵심 사실을 큰 글씨 캡션으로 옆에 박는다.

## 2. 섹션 설계 — 유형별 표준

`references/design-system.md` 의 유형별 구조를 그대로 쓴다. 요약하면:

| 유형 | 섹션 수 | 목표 길이 | 반드시 있어야 할 것 |
|---|---|---|---|
| 무료 웨비나·특강 | **8~10** | **7,000~9,000px** | 신청자 혜택 · 일시 4칸 · tutor |
| 무료 전자책 | 7~8 | 8,000px | 보너스 · "진짜 0원인가요" FAQ |
| 유료 디지털 | 12~13 | 15,000px | 무료본 비교표 · 적합/부적합 · 보증 |
| 유료 클래스 | 14~18 | **25,000~28,000px** | 도입 스토리 · 말풍선 3 · 인물 누끼 · 커리큘럼 · tutor |

**무료 모집 페이지가 길면 안 된다.** 결제가 아니라 신청이 목적이라 설득할 것이 적다.
9,000px을 넘기면 섹션이 과했다는 뜻이다. 늘리지 말고 덜어낸다.

**반대로 유료 클래스는 짧으면 안 된다.** 100만 원대를 결제시키려면 저항을 하나씩 다 풀어야 한다.
길이는 섹션을 늘려서가 아니라 **여백(패딩 200px·행간 1.8)** 으로 확보한다.
실측 기준: `landing/aimax-startup/` 27,307px / 18조각.

## 3. HTML 작성

공통 코어 6개(`wrap` `hero` `eyebrow` `lead` `hl` `cta`)는 **레퍼런스에서 그대로 복사**한다.
유형별 컴포넌트도 있는 걸 먼저 쓰고, 없을 때만 새로 만든다.

지켜야 할 것 (어기면 깨진다):
- `body{ width:1080px; word-break:keep-all }` 고정폭. 반응형 아님
- **Pretendard 로컬 `@font-face`** — CDN은 headless에서 안 붙어 맑은고딕으로 렌더된다.
  HTML 옆에 `assets/pretendard/*.woff2` 5종
- `print-color-adjust:exact` — 없으면 배경색이 날아간다
- h1 104 / h2 66 / 리드 30 / 본문 25~27 / 캡션 22, 섹션 패딩 110/90
- 다크 섹션을 3~4개 간격으로. 밝은 섹션만 이어지면 스크롤이 지루하다
- **이모지 금지 · 구어체 · 방어 가능한 수치만**

## 4. 렌더 + 검수

```bash
S=~/.claude/skills
python $S/detail-page/scripts/render_detail.py detail_x.html detail_x_full.png
python $S/detail-page/scripts/render_detail.py thumbnail_x.html thumbnail_x.png --width 1000
python $S/detail-page/scripts/slice_detail.py detail_x_full.png ./slices --width 1080 --chunk 1500
```

**반드시 4~6등분해서 눈으로 본다.** 긴 이미지는 Read로 한 번에 안 보인다.

```python
from PIL import Image
im = Image.open("detail_x_full.png"); W,H = im.size; N = 6
for i in range(N):
    p = im.crop((0, i*H//N, W, H if i==N-1 else (i+1)*H//N))
    p.resize((720, round(p.height*720/W))).save(f"chk_{i}.png")
```

폰트가 Pretendard인가(맑은고딕이면 로딩 실패) · 넘침 · **가격·날짜 숫자 일치** · 다크/라이트 리듬.

**`display:flex` 안에 `<b>`나 `<span>`을 넣으면 글자 사이가 벌어진다.** 각각이 flex 아이템이 되기 때문.
목록 마커는 flex 말고 `position:relative + padding-left + ::before{position:absolute}` 로.

## 5. 카페24 등록

절차·함정 전부 `references/cafe24-register.md`. 요약:

- **API 는 못 쓴다.** 개발자센터 앱에 상품 권한이 없어 403 / authorize 단계에서 `invalid_scope`.
  → 관리자 화면을 Claude-in-Chrome 으로 조작한다
- 진열상태·판매상태 **둘 다 `전체`**
- 배송방법 **`자체배송`** → 배송비 무료. 0원 상품에 배송비가 붙으면 신청이 막힌다
- 판매가는 기본몰에 넣고 **`환율 자동계산`** 클릭 → 나머지 몰(USD·JPY)까지 채워진다
- 상세설명 이미지는 **하나씩** 올려 URL만 확보하고, 마지막에 정렬된 HTML을 통째로 주입
- 대표이미지는 hidden `input#imageFiles` 에 `file_upload` 로 직접 실는다
- 등록 후 `.env` 의 `CAFE24_PRODUCT_NO` 에 새 번호를 쉼표로 추가

## 6. 등록 후

- 상품페이지를 **외부 HTTP 요청으로 받아** 슬라이스 개수·상품명·가격을 문자열 검사
- 안내 문자·메일은 `order-notify` 스킬로 상품번호에 문구를 건다.
  **실제 발송은 사용자 승인을 받고 실행한다**
- 이미지 교체 시 파일명을 바꾼다. 같은 이름이면 캐시 때문에 확인이 안 된다

## 함정

- **가격은 상세이미지 · 썸네일 · 판매채널 3곳 세트로** 바꾼다. 하나만 바꾸면 클레임
- **날짜도 페이지 안 여러 곳에 박힌다.** HERO · 게이트 · FAQ · CTA. 기수가 바뀌면 전부 찾아 고친다
- "판매량 늘수록 인상"이라 썼으면 실제로 그렇게 운영해야 한다 (표시광고)
- 4,000px 넘는 이미지를 에디터에 넣으면 브라우저가 얼어붙는다 → 반드시 슬라이스
- 무료 강의라도 수익 관련 주장은 근거 있는 것만. 면책 문구 삽입 여부는 사용자에게 확인
