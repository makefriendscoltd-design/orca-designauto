## 서체

**Wanted Sans** ([github.com/wanteddev/wanted-sans](https://github.com/wanteddev/wanted-sans), SIL OFL) 한 벌.
Black(900)까지 있어 Pretendard 800으로는 안 되던 무게가 나오는데 싸구려 느낌이 없다.
**BM한나체는 말풍선 속말 전용.** 본문에 절대 쓰지 않는다.

### 말풍선 3개 — 구매 저항이 올라오는 순서

시장조사(소비자원 피해통계 · 바이브코딩 실사용 후기)로 뽑은 실제 반박이다.

| 위치 | 속말 | 무엇이 받아주나 |
|---|---|---|
| 도입부 | "돈이 되는 건 알겠는데.. 나는 뭘 만들 줄 모르는데.." | 90% 제작 성공 · 옆에 앉아 같이 만듦 |
| 전환 직후 | "만들다가 막히면.. 혼자 끙끙대다 또 포기할 텐데.." | **매일 질의응답 바로 답변** · 매주 작업물 점검 |
| 커리큘럼 직후 | "근데 이것도 결국 녹화본만 주는 거 아니야?" | 불신 답변 섹션 4개 |

능력 의심 → 지속력 의심 → 신뢰 의심. **이 순서를 바꾸지 말 것.**

## 가격·일정을 페이지에 넣지 않는다

기수마다 바뀌는데 이미지에 박으면 **상세·썸네일·판매채널 3곳을 세트로** 갈아야 한다.
빼두면 **카페24 판매가만 바꾸면 끝**이다. 대신:
- CTA에 "참가비와 일정은 결제창에서 확인" + **"기수가 올라갈수록 인상 · 매 기수 조기 마감"**
- **구조는 남긴다** — 오프라인 2회차 · 온라인 5개월 · 정원 10명 · 전 과정 VOD. 기수가 바뀌어도 안 변한다

## 고칠 때 주의

- **결제 스크린샷 캡션을 과장하지 말 것.** 원본은 "수강생이 자기 서비스에 결제창을 붙였다"는
  내용이지 판매가 일어났다는 게 아니다. "결제창 연동"으로 잡아뒀다
- **소비자원 통계는 뺐다.** 사실이지만 "업계에 사기가 많다" 프레임이라 톤이 무거워진다.
  되살리려면 불신 섹션의 `.lead` 문단만 교체하면 된다 (HTML 주석에 원문 있음)
- 누끼·캐릭터는 **테두리에서 플러드필**로 키잉했다. 인물 내부 흰옷을 보존하려면 이 방식이어야 한다
- 현장 사진은 **EXIF 회전이 안 먹은 원본**이라 `ImageOps.exif_transpose` 보정 필요
- **썸네일 바닥이 흰색이면 `render_detail.py` 가 여백으로 보고 잘라낸다.**
  맨 아래 12px 블루 띠로 고정해뒀다
- 강사는 **나민수 대표**. (윤동규는 메이크패밀리 웨비나 쪽)

## 카페 모집글용은 상세페이지와 반대 원칙이다

상세페이지는 날짜를 **빼서** 재사용하지만, 카페 모집글은 기수마다 새 글이라
**날짜를 박는 게 맞다.** 대신 손으로 안 고치고 스크립트로 뽑는다.

```bash
python make_cards.py    --gen 5 --label 9월반 --first 2026-09-06   # 카페 첨부 (기본)
python make_timeline.py --gen 5 --label 9월반 --first 2026-09-06   # 롱이미지
```

### 카페엔 롱이미지가 아니라 카드 3장을 쓴다

**처음에 1080×5,439 롱이미지로 만들었다가 유저 지적으로 카드형을 따로 지었다.**
롱이미지는 상세페이지 포맷이다 — 카페 본문에 넣으면 모바일에서 한참 스크롤한다.
카페는 본문에 글을 쓰고 이미지는 **한 화면에 훑히는 카드**여야 한다.

| | 카페 카드 | 롱이미지 |
|---|---|---|
| 크기 | 1080×1350 × **4장** | 1080×5,991 × 1장 |
| 쓰는 자리 | **카페 글 흐름 중간에 나눠 박음** | 상세페이지·노션처럼 길게 읽는 자리 |
| 담는 것 | 1 전체 흐름 / 2 오프라인 2회차 / 3 매일·매주·매달 / 4 복습 라이브 커리큘럼(다크) | 전부 한 장에 |

카드 장수가 바뀌면 `make_cards.py` 의 `N_CARDS` 와 `SUBTITLES` 도 같이 고친다.

**4:5 인 이유** — 카페는 모바일이 주력이고 세로 4:5 가 화면을 가장 크게 먹는다.
가로형은 모바일에서 축소돼 글씨가 안 읽힌다.

`cards_startup.html` 의 `.card` 는 **height 1350px 고정**이다. 내용을 늘리면 조용히
잘리므로 `make_cards.py` 가 렌더 높이를 4,050 인지 검사하고 다르면 멈춘다.
우하단 워터마크(`.mark`)와 겹치기 쉬운 자리라 고친 뒤엔 세 장 다 눈으로 볼 것.

**라이브 요일·시간을 날짜로 바꾸지 말 것 (26-07-30 유저 확정).**
기수마다 정해지는 값이라 이미지에 박으면 매번 클레임 소재가 된다.
처음엔 "8월 24일부터 매주 월요일"로 박았다가 지웠다. 순서만 보여주고
`.memo` 로 "요일과 시간은 기수 시작 전에 안내합니다" 한 줄을 단다.

시간대가 바뀌면 `--t1` / `--t2`.
치환이 1건이 아니면 스크립트가 **즉시 멈춘다** — 옛 날짜가 박힌 이미지가 나가는 게
제일 위험해서 그렇게 짰다. HTML 구조를 고치면 `make_timeline.py` 의 정규식도 같이 고칠 것.

**마스터는 항상 `timeline_startup.html`.** 스크립트가 만드는 `_timeline_Ngi.html` 은
렌더 성공하면 지워진다.
