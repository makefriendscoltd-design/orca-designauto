# 시각 검수

- 전체 렌더를 6구간으로 잘라 qa/region-1..6.png와 montage.jpg로 직접 확인했습니다.
- 현재 라운지 3D 표지는 상하단 동일하며 실제 표시 면적을 크게 배치했습니다.
- 단순 색상 교체가 아니라 도서마다 문제→사례→방법→적용→FAQ 순서를 편집했습니다. ASIDE는 에디터 화면, 스스는 상품사진과 카테고리 관찰, 위임은 지시서와 기록폴더, 제로백은 주제/첫제안 중심입니다.
- 본문 19px×1.859, 행간1.48. 제목36px×1.859, 자간-.035em. 전후 비교18px/400 대41px/800.
- 제목과 설명 애셋의 간격28–30 논리px. 섹션 양쪽70 논리px. 설명 없는 과도한 연결 여백은 사용하지 않았습니다.
- 2차 확인: smartstore “상품 후보를 찾으세요”, delegation “업무지시서 한 장”의 고립 줄을 없앤 뒤 다시 렌더하고 변경 구간을 직접 확인했습니다.
- runtime.json: 가로 넘침0, 이미지 전부 로드, Pretendard 400/500/600/700/800 로드.
- validation.json: 슬라이스는 이미지·문구·카드 내부를 피하고 픽셀 재조립 일치.
- humanize: 최신 설치본 quick-rules 직접 점검, verify_gates exit0/golden PASS.
- 외부 게시·주문·파일 수령은 실행하지 않았습니다.
