## 확인 범위와 한계

- 가격 기준: 현재 공개 API와 기존 카탈로그의 30,000/50,000/무료/30,000/30,000/20,000/0원.
- 새 수익·효능 숫자나 판매후기를 지어낸 화면은 확인하지 못했습니다. 원문 사례와 설명용 구성은 라벨로 분리됩니다.
- landing-page와auto-funnel은 원문에 실제사진이 적어 코드 설명 카드 비중이 큽니다. 사용자의 “이해를 돕는 애셋” 목적에는 부합하나 실사 비중 자체는 PDF4권보다 낮습니다. 발행 차단 사유로 판단하지 않았습니다.
- 소액본문·원문발췌 글씨는 축소 몽타주에서 모두 읽도록 만든 요소가 아닙니다. 큰 제목과 인접캡션이 핵심을 설명합니다.
- 외부상품의 실제 적용, 구매자메일, 로그인 계정의 권한과 다운로드는 이번 독립 시각검수에서 실행하지 않았습니다. 각 작업자의 자동 QA와 별도로 운영검증은 root 범위입니다.
- 법률적 적정성이나 가격정책을 새로 판단하지 않았습니다. 기존정책과 명시값의 내용대조 범위입니다.
