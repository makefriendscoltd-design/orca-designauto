## 섹션 구성 (12)

HERO(다크) → 신청게이트(연오렌지) → 문제제기 → 다크선언 5천만vs80억 → 수익화구조 브리지 →
**증거(서류·카톡·카페후기)** → 강사(다크) → AI장벽해소 → 커리큘럼6 → 결과물9(연오렌지) →
적합/부적합 → CTA(오렌지 풀블리드)

무료 리드마그넷 기본은 7섹션이지만, **"수출은 대기업만 하는 일"이라는 저항이 커서**
증거 섹션과 AI 장벽 해소 섹션을 추가해 12섹션으로 갔다.

## 고칠 때 주의

- **날짜가 4곳에 박혀 있다** — HERO `.whenbox`, 게이트 STEP 3, FAQ "다시보기" 답변, CTA `.when2`.
  기수가 바뀌면 네 곳을 세트로 고친다
- **다시보기 없음도 4곳** — 게이트 `.rd`, FAQ, CTA `.fine`, (HERO metabar는 "신청자 한정"만).
  무료라 희소성 장치가 이것뿐이라 살려 쓰고 있다. 다시보기를 주게 되면 네 곳을 같이 지운다
- 증거 이미지의 파란/빨간 마스킹은 원본 그대로다. 새 이미지를 넣을 땐 **업체명·금액 노출 여부를 먼저 확인**
- 면책 문구는 유저 판단으로 뺐다(무료 강의). 유료 전환 시엔 다시 넣을 것
- `.reviews li` 는 flex가 아니라 `position:relative + padding-left` 다.
  flex로 되돌리면 안쪽 `<b>`가 별도 flex 아이템이 돼 글자 사이가 벌어진다

## 카페24 등록 — 완료 (26-07-29)

0원 신청 상품으로 등록했다 — **주문 = 웨비나 신청서, 주문자 정보가 곧 DB.**

| 항목 | 값 |
|---|---|
| product_no | **279** (상품코드 `P0000OKT`, 목록 No 206) |
| 상품명 | `[무료웨비나] 직장인을 위한 수출 매칭 수익화 클래스` |
| 관리용명 | `실크로드 수출매칭 웨비나 0810` |
| 상품분류 | `-` (관리자에 실제로 "-" 라는 분류가 있다) |
| 메인 진열 | `무료 웨비나 리스트` |
| 진열·판매 | 4개 몰 전체 (한국어 2 / 영어 / 일본어) |
| 판매가 | 0 — **환율 자동계산**으로 KRW·USD·JPY 전부 0 |
| 상세설명 | slices s0~s11 12장 |
| 관리자 | `/disp/admin/product/productmanage?product_no=279` |
| 상품페이지 | `/product/detail.html?product_no=279` |

**API 가 아니라 관리자 화면 자동화로 등록했다.** 개발자센터 앱에 **상품·상품분류 권한이 없어서**
`/api/v2/admin/products` 는 403 insufficient_scope 이고, authorize 단계에서 `invalid_scope` 로 튕긴다.
(07-27 에 추가한 건 주문·배송 4개뿐.) API 로 하려면 개발자센터에서 권한을 켜고 `auth.py` 재인증해야 한다 —
그때 **`.env` 의 `CAFE24_SCOPE` 8개를 그대로 두고** 인증할 것. shipping 을 빼면 배송완료 자동화가 죽는다.
API 용 스크립트는 `orca/projects/cafe24/register_webinar.py` 에 준비돼 있다(권한 풀리면 바로 실행 가능).

`.env` 의 `CAFE24_PRODUCT_NO` 를 `275,279` 로 바꿔서 **auto_ship 이 이 웨비나 신청 주문도
자동 배송완료 처리**하게 해뒀다.
